# 如何把 Daily Checklist 导入 iPhone / Apple Watch

有两种方式,推荐第一种(15 秒完成),第二种更灵活但要手动建 19 条。

---

## 方案一(推荐)⭐️:iCloud 日历 ICS 一键导入

用 `recovery-checklist.ics` 文件,一次导入 19 个循环事件到日历,每一条都会自动出现在 Apple Watch。

### 步骤

**1. 把 ICS 文件传到 iPhone**

任选一种方式:
- AirDrop:在 macOS Finder 里选中 `recovery-checklist.ics` → 分享 → AirDrop → 发给自己
- 微信/邮件:发给自己,在 iPhone 上点开附件
- iCloud Drive:把文件放到 `~/Library/Mobile Documents/com~apple~CloudDocs/` 下,iPhone 文件 App 打开

**2. 在 iPhone 上打开这个文件**

- 点击 `.ics` 文件
- 弹出「添加全部事件」→ 选择日历(建议**新建一个日历**叫「Recovery」,方便以后单独隐藏/删除)
- 点「添加」

**3. 完成**

- 打开日历 App,所有事件已经在
- Apple Watch 自动同步,腕上会收到提醒
- 每个事件都设置了默认弹窗提醒

### 事件清单(共 19 个)

**每日(13 个)**:
- 07:30 起床晒太阳
- 12:00 最后一杯咖啡
- 12:30 午餐
- 12:45 Coffee Nap
- 13:15 餐后散步
- 14:00 之后不再喝咖啡因
- 16:00 加餐 + 起身
- 18:30 晚餐
- 21:00 停止进食
- 22:30 深呼吸
- 23:00 手机灰度
- 23:30 手机放客厅
- 01:00 关灯睡觉

**工作日(3 个)**:
- 09:45 早餐
- 10:30 起身 2 分钟
- 14:30 起身 2 分钟

**周一/三/五(1 个)**:
- 08:15 公司晨跑 30 分钟

**周三/五/六(1 个)**:
- 22:00 家里力量训练

**每周日(1 个)**:
- 20:00 本周复盘

### 起始日期

首次触发从 **2026-08-25(周二)** 开始,你今晚(周一)导入,明早 07:30 就会响第一次。

### 后续调整

**改时间**(比如作息进入第 2 周要把关灯时间从 01:00 改到 00:30):
- iPhone 日历里长按事件 → 编辑 → 修改时间 → 选「所有未来事件」

**停用某条**(比如晨跑改到晚上了):
- 长按 → 删除 → 选「所有未来事件」

**整个清单不用了**:
- 设置 → 日历 → 账户 → iCloud → 关闭「Recovery」日历

## 方案二(灵活):手动建 iPhone 提醒事项

如果你更习惯用**提醒事项**(可以勾选打钩,像 todo list),而不是日历弹窗,可以手动建。

### 步骤

**1. 打开提醒事项 App**

**2. 左下角「添加列表」→ 命名「Recovery」→ 选颜色(推荐绿色)**

**3. 逐条添加下面 19 条**

每条添加时:
- 输入标题
- 点右边的 (i) 图标
- 打开「日期」→ 选日期
- 打开「时间」→ 选时间
- 打开「重复」→ 选每日 / 工作日 / 自定义(周一三五 / 周三五六)
- 「早期提醒」如果需要提前提醒可以设

### 快速添加语法(iOS 支持自然语言)

在提醒事项输入框里,直接输入这样的文本会自动解析:

```
☕️ 今日最后一杯咖啡 每天 12:00
🥗 午餐 每天 12:30
🚶 餐后散步 15 分钟 每天 13:15
🥜 加餐 + 起身 每天 16:00
🍽️ 晚餐 每天 18:30
⛔️ 停止进食 每天 21:00
🧘 深呼吸 1 分钟 每天 22:30
📵 手机灰度 每天 23:00
🛏️ 手机放客厅 每天 23:30
😴 关灯睡觉 每天 01:00
☀️ 起床晒太阳 每天 07:30
🥚 早餐 工作日 09:45
🧍 起身 2 分钟 工作日 10:30
🧍 起身 2 分钟 工作日 14:30
⛔️ 不再喝咖啡因 每天 14:00
🏃 公司晨跑 每周一三五 08:15
🏋️ 家里力量训练 每周三五六 22:00
😴 Coffee Nap 每天 12:45
📊 本周复盘 每周日 20:00
```

**技巧**:iOS 会识别「每天」「工作日」「每周三」等中文,自动设成重复。

### 提醒事项 vs 日历,选哪个?

| 特点 | 日历(方案一) | 提醒事项(方案二) |
|---|---|---|
| 提醒方式 | 弹窗通知 | 通知 + 可勾选打钩 |
| 有完成感 | 弱 | 强(勾掉的成就感) |
| Apple Watch 显示 | 手表表盘可显示当前事件 | 复杂功能,需要专门加复杂功能 |
| 批量导入 | ✅ ICS 一键 | ❌ 只能手动 |
| 修改成本 | 低 | 中等 |
| **推荐场景** | 时间提醒为主 | **想追踪完成率、勾选打卡** |

### 我的建议

**两个都用**:
- **日历(ICS)**:装大部分时间提醒(19 个都装)
- **提醒事项**:只装每天最核心的 7 件事,勾选式打卡,晚上看有几个没勾,一目了然

每天最核心的 7 件(建提醒事项):

1. ☀️ 早餐
2. ☕️ 咖啡 12:30 前
3. 🥗 午餐先菜后肉
4. 🚶 餐后散步
5. ⛔️ 21:00 后不进食
6. 📵 23:00 手机灰度
7. 😴 目标时间前关灯

## Apple Watch 表盘配置(锦上添花)

**推荐表盘**:模块化 / 信息图 / 天梭风格(有多个复杂功能位)

**推荐加载的复杂功能**:

| 位置 | 建议 |
|---|---|
| 中心大区域 | 活动记录(3 个圆环) |
| 左上角 | 日历(下一个事件)—— 就是你刚导入的 Recovery 事件 |
| 右上角 | 心率 |
| 左下角 | 睡眠 |
| 右下角 | 呼吸(点一下开始 1 分钟深呼吸) |

设置路径:
- Apple Watch 上长按当前表盘 → 编辑 → 复杂功能

## 一句话总结

**AirDrop 导入 recovery-checklist.ics → 日历 App → 添加到「Recovery」日历 → 完成。19 个提醒同时上线。**

## 附:如果 ICS 导入有问题

**问题 1:导入后没有响应**
- 检查:设置 → 日历 → 默认账户 → 选 iCloud(不是"我的 iPhone")
- iCloud 账户下的日历才会同步到 Apple Watch

**问题 2:时间不对**
- 检查:设置 → 通用 → 日期与时间 → 时区 → 上海
- 我的 ICS 已经写死了 `Asia/Shanghai`,应该不会错

**问题 3:提醒没响**
- 检查:设置 → 通知 → 日历 → 打开「允许通知」
- 检查专注模式(如"睡眠"模式)是不是屏蔽了

**问题 4:想改所有事件的时间**
- iPhone 上直接改一个,选「所有未来事件」
- 或者改我这个 ICS 文件,重新导入前先删除旧的 Recovery 日历
