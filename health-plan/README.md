## 三周启动计划

### 第 1 周(2026-08-24 起)

- 睡眠:01:00 睡 / 08:30 起
- 咖啡:改到 12:30 前一杯
- 早餐:一杯无糖豆浆 + 香蕉
- 运动:先徒手训练 + 尝试快走 30 分钟
- 装备:京东下单哑铃 + 卧推凳
- 心理:研究简单心理平台,准备约首次咨询
- 医疗:挂号内分泌 / 消化内科(2 周内)

### 第 2 周

- 睡眠:00:30 睡 / 08:00 起
- 运动:哑铃到货,正式开始力量 A/B/C
- 早餐升级到蛋白质版本
- 医疗:完成首次体检 + 拿到 baseline 数据

### 第 3 周起

- 睡眠:00:00 睡 / 07:30 起(稳定作息)
- 完整跑动六大维度
- 第 4 周开始首次心理咨询

## 每周日复盘

在提醒事项 App 设置每周日 20:00 提醒,按 [daily-checklist.md](./daily-checklist.md) 的复盘模板做 3 分钟回顾。
