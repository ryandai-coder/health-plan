# 每日打卡清单

> 每天早/中/晚各扫一眼,勾选。周日晚做一次周复盘。
> 可以直接在 iPhone 备忘录里勾选,或者做成 iPhone 提醒事项模板。

## 每日打卡表(复制到备忘录/提醒事项)

### ☀️ 早上(07:30 - 10:00)

- [ ] 07:30 起床(不按贪睡)
- [ ] 晒 10 分钟太阳(阳台/窗边)
- [ ] 喝一杯 300ml 温水
- [ ] 早餐:无糖豆浆 + 香蕉(或蛋白质版本)
- [ ] 通勤末端走 10 分钟

### 🏢 上午(10:00 - 12:00)

- [ ] 「深度工作」专注模式开启
- [ ] 10:30 起身 2 分钟(15 个空蹲 or 上厕所)
- [ ] 至少喝 500ml 水

### 🍱 中午(12:00 - 13:30)

- [ ] 午餐(食堂:1 份糙米 + 1 素 + 2 荤,先吃菜后吃肉最后主食)
- [ ] ☕️ 今日唯一一杯咖啡(12:30 前喝完)
- [ ] 午睡 20-25 分钟(闹钟设 25 分钟)
- [ ] 起来喝 300ml 水

### 🏢 下午(13:30 - 21:30)

- [ ] 14:00 起身 2 分钟
- [ ] 16:00 加餐(无糖酸奶/坚果/水煮蛋)+ 起身 2 分钟
- [ ] ⛔️ 14:00 之后不喝咖啡因(茶也算)
- [ ] 全天水量目标 2000ml

### 🌙 晚上(21:30 - 24:00)

- [ ] 21:30 下班,「个人时间」专注模式开启
- [ ] 晚餐(蛋白质 + 蔬菜为主,主食减半,21:00 前吃完)
- [ ] 训练日:22:00-22:45 力量训练(周三/周五/周六)
- [ ] 非训练日:散步 20 分钟 or 伴侣时间
- [ ] 22:30 深呼吸 1 分钟(Apple Watch 呼吸 App)
- [ ] 23:00 手机自动切灰度(Shortcuts 自动)
- [ ] 23:30 手机放客厅充电
- [ ] 洗澡 + 拉伸 5 分钟
- [ ] 睡前写 3 行:今天发生了什么 / 我感受到什么 / 明天想做什么
- [ ] 01:00 关灯(渐进目标:3 周后 24:00)

## 每日核心 7 件事(如果只做这 7 件)

如果哪天状态差,只保证这 7 件:

1. ☀️ 早餐(哪怕只是一杯无糖豆浆)
2. ☕️ 咖啡 12:30 前喝完
3. 🥗 午餐先吃菜再吃肉最后主食
4. 🚶 午餐后散步 15 分钟
5. ⛔️ 21:00 后不再进食
6. 📵 23:00 手机灰度
7. 😴 目标时间前关灯睡觉

**做到这 7 件,一天就是及格。**

## 训练日额外打卡

### 🏋️ 家里力量训练日(周三/周五/周六 22:00)

- [ ] 训练前吃一根香蕉(如晚餐距训练超过 2 小时)
- [ ] 热身 5 分钟(高抬腿 + 关节活动)
- [ ] 主训练 30 分钟(按 A/B/C 模板)
- [ ] 拉伸 5 分钟
- [ ] 训练后 30 分钟内补蛋白质(2 蛋 + 牛奶,或乳清蛋白粉)
- [ ] Apple Watch 训练 App 记录

### 🏃 公司晨跑日(周一/周三/周五)

- [ ] 8:00 到公司换衣服
- [ ] 8:15-8:45 跑步 30 分钟(园区/跑步机)
- [ ] Apple Watch 户外跑步记录
- [ ] 跑完擦汗换衣 + 早餐
- [ ] 10:00 准时开工

## iPhone 提醒事项配置

| 时间 | 提醒 | 重复 |
|---|---|---|
| 07:30 | ☀️ 起床晒太阳 10 分钟 | 每日 |
| 09:45 | 🥚 早餐 | 工作日 |
| 10:30 | 🧍 起身 2 分钟 | 工作日 |
| 12:00 | ☕️ 今日最后一杯咖啡 | 每日 |
| 12:30 | 🥗 午餐(菜→肉→饭) | 每日 |
| 12:55 | 🚶 餐后散步 15 分钟 | 每日 |
| 13:30 | ⛔️ 之后不再喝咖啡因 | 每日 |
| 14:00 | 🧍 起身 2 分钟 | 工作日 |
| 16:00 | 🥜 加餐 + 起身 | 每日 |
| 18:30 | 🍽️ 晚餐 | 每日 |
| 21:00 | ⛔️ 停止进食 | 每日 |
| 22:00 | 🏋️ 训练日:家里力量训练 | 周三/五/六 |
| 22:30 | 🧘 Apple Watch 深呼吸 | 每日 |
| 23:00 | 📵 手机灰度(Shortcuts 自动) | 每日 |
| 23:30 | 🛏️ 手机放客厅 | 每日 |

**技巧**:提醒事项里,长按提醒 → 详细信息 → 打开「位置」→ 选择「工作」/「家」,可以做到"到公司时提醒"或"回家时提醒"。

## 打卡记录模板(可选,进阶)

如果你想追踪进度,可以在备忘录里每天记一行:

```
2026-08-24 周一
睡眠: 01:15-08:30(7h)  深睡 1.4h  HR 68
早餐: 无糖豆浆+香蕉 ✅
午餐: 食堂糙米+清蒸鱼+菜心+豆腐 ✅
午后散步: ✅ 15min
咖啡: 12:30 ✅
加餐: 卡士酸奶 ✅
晚餐: 白灼虾+时蔬+半碗米饭 ✅  20:15
训练: 无
心情: 6/10
备注: 下午精神状态明显好于昨天
```

**连续记 30 天,趋势就非常清楚了。**

## 惩罚 vs 奖励机制

**不建议惩罚**(自责会加重心理压力),推荐**奖励**:

- 连续 7 天完成核心 7 件事 → 买一件想买的东西(< 500 元)
- 连续 1 个月坚持训练 → 一次好餐厅(选清蒸/白灼类)
- HbA1c 3 个月后下降到正常 → 一次周边短途旅行

## 一句话记忆

**每日 7 件事、周日 3 分钟复盘、连续记录 30 天看趋势。**
