# 医疗随访清单

> 免责声明:本文档为生活规划参考,不能替代医生的诊断和治疗方案
> 用户情况:早期糖尿病 + 轻/中度脂肪肝 + 近一个月 ED

## 为什么现在必须去医院

- **早期糖尿病是可逆的**,晚期不是。窗口期就在这 1-2 年
- **脂肪肝到肝纤维化再到肝硬化**,是慢性但持续的进展
- ED 一个月,需要排除生理性原因(睾酮低、血管问题)
- 生活方式调整需要**基线数据**作参考,3 个月后才知道有没有效果

## 首次体检:2 周内完成

### 挂号科室

| 科室 | 目的 | 优先级 |
|---|---|---|
| **内分泌科** | 糖尿病评估、性激素、甲状腺 | ⭐️⭐️⭐️ 必须 |
| **消化内科 or 肝病科** | 脂肪肝分级、肝功能 | ⭐️⭐️⭐️ 必须 |
| **男科 or 泌尿外科** | ED 评估(如果 2 周戒断后无改善) | ⭐️⭐️ 视情况 |
| **心理科 or 精神心理科** | 抑郁/焦虑筛查(可选,咨询师也可) | ⭐️⭐️ 推荐 |

**建议策略**:先挂**内分泌科**做全面血检,80% 的问题都能查出线索,再根据结果决定要不要看其他科。

### 首次要做的检查清单

**血液检查(空腹 8 小时以上)**:

| 项目 | 说明 |
|---|---|
| 空腹血糖(FPG) | 糖尿病诊断基础 |
| **糖化血红蛋白(HbA1c)** | 反映过去 3 个月平均血糖,金标准 |
| 口服葡萄糖耐量试验(OGTT) | 如果 HbA1c 在临界值,做这个更准 |
| 空腹胰岛素 + C 肽 | 评估胰岛功能 |
| **肝功能全套**(ALT/AST/GGT/ALP/胆红素) | 脂肪肝严重程度 |
| 肝纤维化四项(可选) | 排除已发生纤维化 |
| **血脂四项**(TC/TG/HDL/LDL) | 脂肪肝常合并血脂异常 |
| **性激素六项** + 游离睾酮 | 排除低睾酮性 ED |
| 甲状腺功能(TSH/FT3/FT4) | 疲劳/情绪低下可能是甲减 |
| 25-羟维生素 D | 久坐室内基本都缺,影响睾酮和情绪 |
| 血常规 + 尿常规 + 肾功能 | 基础全套 |
| 高敏 C 反应蛋白(hsCRP) | 慢性炎症指标 |
| 尿酸 | 代谢综合征常合并高尿酸 |

**影像/其他**:

| 项目 | 说明 |
|---|---|
| **腹部 B 超**(重点看肝) | 脂肪肝分级(轻/中/重度) |
| 肝脏瞬时弹性成像(FibroScan) | 如果 B 超提示中度以上,做这个看纤维化程度 |
| 心电图 | 基础筛查 |
| 血压测量 | 医生诊室量,或买个欧姆龙家用血压计每周量 |
| 身高体重腰围 | 建立基线 |

**费用预估**:全套自费大约 1500-2500 元,医保报销后 500-1000 元。

## 复查节奏

**目标**:通过 3-6 个月的生活方式调整,让 HbA1c 和肝功能回到正常范围。

| 时间 | 复查项目 | 目的 |
|---|---|---|
| **首次就诊后 3 个月** | 空腹血糖 + HbA1c + 肝功能 + 血脂 | 看趋势,是否需要药物介入 |
| **6 个月** | 全套复查 + 腹部 B 超 | 脂肪肝是否消退 |
| **12 个月** | 首次的全套(含性激素) | 年度体检 |
| 症状变化时 | 随时挂号 | 不要拖 |

## 何时必须立刻就医(而非常规挂号)

**糖尿病急症**:
- 极度口渴、大量喝水尿多、体重快速下降 → 可能酮症酸中毒
- 意识模糊、极度乏力 → 低血糖或高血糖危象

**心血管**:
- 胸痛、胸闷、气促 → 立即急诊
- 突发单侧肢体麻木无力、言语不清 → 立即急诊(疑似脑卒中)

**心理**:
- 出现自伤/自杀想法 → 立即联系:上海市心理援助热线 **021-64383562** 或 **12320-5**

## 检查结果保存

**建议做法**:
- 每次检查完拍照存到 iCloud 相册的「健康」相簿
- 关键指标(HbA1c、ALT、AST、总睾酮、维生素 D)记录到备忘录里,做趋势追踪
- 未来 3 个月一次复查,能明显看到"生活方式改善" → "指标下降"的正反馈

## 一句话记忆

**2 周内挂内分泌 + 消化科、做全套血检 + 肝 B 超、3 个月复查看趋势。**
